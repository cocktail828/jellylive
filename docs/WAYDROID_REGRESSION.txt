实际问题和修复
1. Material Button 默认 StateListAnimator 使按钮 Z 高于后添加的文字。
   原生检查发现 buttonZ=4、labelZ=0；选中背景和焦点背景覆盖标签。
   TvUi 统一关闭这层系统抬升，保留自定义焦点；直播分组、设置和播放器共用修复。
2. 设置选项缺少列内方向关系，系统空间搜索会跳回分类或停在错误项。
   按视觉位置排序设置动作，补全上下边界、左回分类、右留本列，过滤失效焦点。
3. 实际海报加载后打开筛选触发 software Canvas 不支持 hardware bitmap 的崩溃。
   媒体页面图片请求关闭 hardware bitmap；其他页面默认不变。
   TvGlass 快照失败时恢复 panel alpha 并保留可读底色，模糊不可用也不使弹层消失。
4. 飞牛影视连接缓存冷启动跳过 PublicInfo，进程内协议识别丢失，DTO 空 UUID 解析失败。
   从已缓存的服务器名称/地址恢复识别，再请求数据；只识别已知飞牛来源。
5. 按用户要求删除详情“更多”。剩下三项等宽，普通字号224、大字号342逻辑宽度。
   大字号设置标题、详情简介、播放器标题、缓冲提示与频道编号同步消除实屏裁切。
6. 进入媒体库时释放直播播放器和定时任务；返回时重建并恢复频道。
   拒绝已释放播放器的迟到回调，避免两个页面同时保留解码器。
