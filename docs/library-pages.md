# 媒体库页面与交互基准

以用户最终确认的总画册图15、图16为准。图15是首页，图16是分类海报列表，两页分别组装；后续“首页直接摆电影海报”的提案已撤回。

图15上方显示真实的继续观看记录，下方平铺电影、剧集、最近添加三个入口卡片。入口立即可用，不等待全库下载；没有续播时入口区上移。点击入口进入对应的图16，最近添加按添加时间倒序。返回保留入口焦点和滚动。

图16只有当前分类的标题、真实总数、海报和分页。右上顺序固定为搜索媒体、筛选、排序；筛选默认文案为“类型：全部”。普通字号六列、大字五列，海报图片为2:3；分页范围居中，两侧箭头在边界禁用。页内不复制首页导航或两排工具按钮。

生产坐标集中在 `LibraryPageLayout.kt`，采用960×540逻辑坐标，对应原稿1920×1080的二分之一。普通布局沿用原稿位置；大字布局调整为五列并下移分页，避免标题、元信息和分页重叠。入口插画沿用原稿的原生矢量场景。

## 筛选和排序

点击筛选打开右侧侧栏，在同一滚动区域选择观看状态、类型、上映年份、分辨率、地区；缺少可靠数据的组隐藏。筛选项保持现有单选语义，跨组叠加。条件、排序及方向选择立即生效，没有应用按钮；侧栏保持打开，关闭或返回保留选择。重置立即清空筛选，保留当前分类及排序。

即时更新只替换海报区域、计数和工具文字，保留页面与弹层对象及焦点。类型等选项来自当前分类完整范围，筛选和分页使用相同范围。异步结果按选择与页码隔离，防止旧结果覆盖新选择，包括快速A→B→A回到缓存的情况。

从列表进入详情、播放器或搜索后，返回恢复原列表、条件、排序、分页和焦点。后台续播请求不抢占已经操作用户或其他页面的焦点；历史页面按媒体库会话隔离。

## 验证

在现有容器执行 `scripts/check-container.sh` 和 `scripts/check-library-container.sh`。检查包含真实生产坐标边界、分类入口语义、即时选择、异步结果隔离，以及已有协议与交互回归。

生产坐标和原生插画可导出SVG布局模拟用于与设计对照；模拟不等同于Android截图。实际字体测量、焦点移动、触摸、图片加载仍需在设备上验证。
